Инструкция по запуску:

1. Скачайте и распакуйте ZIP-архив проекта.

2. Дважды кликните на файл index.html, чтобы открыть его в любом современном браузере.

Список реализованных JS-функций:

1. Мобильное меню (гамбургер): адаптивное открытие и закрытие навигации по клику на кнопку ☰ на экранах телефонов.

2. Плавная навигация: скроллинг страницы к соответствующим секциям при клике на ссылки в меню.

3. Интерактивные анимации карточек: динамический подъем карточек проектов (hover-эффект) при наведении курсора мыши.
